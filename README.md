# FDSA landingsside (prototype)

Designskisse og klikkbar prototype for en landingsside om Forsvarets datasentriske arkitektur (FDSA).

**Status:** Utkast. Ikke en offisiell publisering fra Forsvaret.

## Innhold
- `index.html`: hele siden i én fil (fonter, logo, bilder og diagrammer er innebygd). Åpnes direkte i nettleser.
- Tospråklig (norsk/engelsk).
- Interaktivt: klikkbare DRP-prinsipper, FAKTISK-kriterier og FDDP-skalaer åpner sidepaneler.

## Viktig å vite
- Bildene er eksempler og skal erstattes med godkjent fotografi.
- Forklaringene av DRP-prinsippene er omskrevet og må byttes med ordlyden i DRP 2026.
- FAKTISK-eksemplene er ikke kvalitetssikret av fagmiljøet.
- Kontaktskjema og dokumentlenker er ikke koblet opp.
- Universell utforming (WCAG 2.1 AA) er ikke testet.

## Videre arbeid
Siden er et spesifikasjonsgrunnlag. Produksjonsversjonen bygges i publiseringsløsningen til forsvaret.no.
